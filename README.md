# ÉLIXOR Hair Care

Landing page indépendante pour ÉLIXOR Hair Care Spray 100 ml.

## Développement

- `npm install`
- `npm run dev`
- `npm run build`

Le formulaire est une prévisualisation et ne transmet pas encore les commandes. Prévoir un backend dédié avant la mise en production.

## Cloudflare Pages
- Build command : `npm run build`
- Output directory : `dist`
